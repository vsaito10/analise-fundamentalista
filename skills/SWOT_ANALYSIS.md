# SWOT — Empresas Listadas
 
## Regras
 
1. Confirme ticker/bolsa antes de começar
2. Use web_search para dados recentes (RI, CVM/SEC, releases)
3. Fundamente cada fator com dado quantitativo ou fonte
4. Preencha os 4 quadrantes — nunca omita nenhum
5. Classifique cada fator: Magnitude Alta/Média/Baixa
## Quadrantes
 
- **Forças (Interno+):** ROIC, margens vs peers, market share, marca, patentes
- **Fraquezas (Interno−):** endividamento, concentração, litígios, governança
- **Oportunidades (Externo+):** TAM, M&A, regulação favorável, tendências
- **Ameaças (Externo−):** concorrência, disrupção, regulação, macro adverso
## Entrega
 
Matriz TOWS (S-O, W-O, S-T, W-T), diagnóstico e implicações para investidor. Use `docx`/`xlsx`/`pdf` se pedido.
